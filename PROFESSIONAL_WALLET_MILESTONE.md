# Professional Wallet Milestone

This milestone removes development/simulation language from customer-facing wallet surfaces and adds connected-wallet management.

- Fixes `site_logo_light()` / `site_logo_dark()` compatibility with legacy settings.

- External wallet connection records with provider, network, address, label, primary state and disconnect flow.
- New `/wallet/connections` area.

Portfolio/test disclosure remains documentation-level rather than repeated through customer UI.
